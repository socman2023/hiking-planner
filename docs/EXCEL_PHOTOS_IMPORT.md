# Hiking Planner — Excel, LighterPack, фотографии и размещение вещей

**Обновлено:** 18 ноября 2026  
**Приложение:** https://socman2023.github.io/hiking-planner/library

## Источники и импорт

- Excel: «Крым_4_дня_оптимизирован_все_листы.xlsx» и «Архыз_4 дня.xlsx».
- Excel: 43 продукта, 43 фасовки, 113 исходных строк снаряжения / 111 различающихся карточек, 27 лекарств/медизделий, 54 исторических записи упаковок.
- Все четыре предоставленных публичных списка LighterPack: [a9cua5](https://lighterpack.com/r/a9cua5), [4pg9c9](https://lighterpack.com/r/4pg9c9), [gdl4a](https://lighterpack.com/r/gdl4a), [0lr1s5](https://lighterpack.com/r/0lr1s5).
- Из LighterPack фактически получены **309 + 99 + 159 + 81 = 648 исходных позиций**, включая названия, описания, категории, веса по спискам, количество и ссылки на изображения (в исходнике 633 URL фото). Снимки Imgur остаются внешними ссылками, пока не сохранены пользователем локально.
- LighterPack-данные извлечены запущенным в GitHub Actions `scripts/build-lighterpack-seed.mjs` в `public/seed/lighterpack.json`; клиентский импорт `src/data/importLighterPackSeed.ts` обрабатывает и консервативно объединяет модели без удаления пользовательских карточек.
- При совпадении подробного описания модели в Excel и LighterPack записывается один предмет. Вес из LighterPack хранится отдельно в **«Вес из походного списка, г»**, а не в неподтверждённой массе производителя.

## Фото

- Исправленная папка Google Drive: https://drive.google.com/drive/folders/1URbLYmZbaCL-sdozFKcrglbbmGOvBQ_3
- В `public/seed/photos` опубликованы **110 локальных фотографий**, сопоставленных с исходными карточками Excel по модели или типу. `docs/GEAR_PHOTO_SOURCES.json` хранит происхождение каждой.
- **Точное соответствие** и **иллюстративная фотография типа** различаются; похожая вещь не выдаётся за проверенный снимок конкретной модели.
- Дополнительно в LighterPack содержатся 633 ссылок на фото. Они могут отображаться в карточках новых моделей, но требуют сети и доступности Imgur. Это **не** 633 дополнительных локальных изображения.
- Для карточек предусмотрена загрузка до 4 собственных фотографий JPG/PNG/WebP. Они уменьшаются в браузере и сохраняются в IndexedDB и JSON-бэкапе. Локальные фото имеют приоритет над фотографиями из источников.
- Не публикуем изображения личных документов, персональных ключей и другие приватные материалы только ради формального заполнения всех карточек.

## Заметки и походные вещи

- Служебные фразы предыдущего импорта («Место хранения/носки», «Связанная ссылка LighterPack», «Импортировано из похода» и пр.) автоматически удаляются из существующей локальной библиотеки при открытии страницы и отсеиваются при следующих импортах через `src/data/cleanLibraryNotes.ts`.
- В примечаниях остаются только содержательные данные. Ссылки на источники сохраняются в самостоятельном поле/разделе «Источники».
- **Место размещения, количество, способ переноски, собран/не собран и заметки о комплектации** хранятся теперь отдельно для каждого похода (Dexie v3 `tripGear`). Интерфейс доступен из карточки соответствующего похода по кнопке «Снаряжение похода».
- Файлы полных резервных копий версии 3 включают списки вещей по походам; перенос в другое устройство требует импорта JSON.
