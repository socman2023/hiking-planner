# Проверка этапа 1

Контрольный документ для CI через pull request.

Проверяемые сценарии:

- TypeScript: строгая проверка типов без запуска внешних API.
- Unit: создание, обновление, копирование и удаление походов и календарных дней.
- Unit: ISO-даты, високосный год, резервная копия, атомарное восстановление.
- Browser Chromium desktop/mobile: создание похода, редактирование дня, изменение длительности, дублирование, резервный экспорт/импорт.
- Production: Vite-сборка.

Реальные результаты записывать только после выполнения CI. Документ не является отчётом об уже пройденных тестах.
