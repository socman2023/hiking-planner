## 1. Принятые решения

- Рабочее имя — **Hiking Planner**; репозиторий **hiking-planner**. Название демонстрационного прототипа Qwen не используется.
- Приоритетный пользователь — **одиночный турист**; групповой функционал исключён из первоначального продукта.
- Веб-приложение с адаптивным интерфейсом; PWA планируется после появления полноценных рабочих функций.
- React + TypeScript + Vite; IndexedDB через Dexie; React Router; бизнес-вычисления отдельными чистыми функциями.
- Не нужны Supabase, Cloudflare, отдельный сервер, аккаунты пользователей или платные API для этапов 0–1.
- Внешние API: Open-Meteo, OSM/Overpass, открытые данные о продуктах, разрешённые каталоги/источники снаряжения и лекарственных инструкций. Каждый источник имеет независимый адаптер; ручной импорт при недоступности API.
- Карта — реальная OSM-совместимая подложка (первый вариант Leaflet), не фиктивная SVG-карта. Офлайн-карты не скачивать массово с публичного OSM.
- Личная библиотека переиспользуемых продуктов/фасовок, блюд, предметов снаряжения, лекарств/изделий, треков и геообъектов.
- Все расчётные итоги производные. Неизвестный вес, цена, нутриент, срок годности или факт расхода не равны нулю.
- Источник/дата/подтверждение на карточках, внешние данные не перезаписывают подтверждённые пользователем сведения без согласия.
- Медицинские материалы — справочник по официальным инструкциям, а не автоматические медицинские назначения.

## 3. Что **не** сделано

- Нет рабочего React-приложения, `package.json`, `npm`-зависимостей, схемы Dexie в коде, UI или API-адаптеров.
- Нет автоматических тестов/CI и результатов `npm ci`, `npm test`, `npm run build`.
- Не выполнено чтение и точное сопоставление всех ячеек исходного Excel с новой моделью: оригинал прежней загрузки не доступен в текущей рабочей среде. Названия девяти листов известны из обсуждения, но это **не заменяет** повторную построчную проверку.
- Оценка дизайна Qwen базируется на доступном HTML-референсе; его код не переносился в новый репозиторий и не считается проверенной логикой.
- Никакие сторонние API не подключены и их браузерная доступность не проверена в рабочем приложении.
- Статический хостинг, облачная синхронизация и группы не создавались.
