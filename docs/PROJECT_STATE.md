## Реализовано

### Этап 0
- Техническое задание, архитектура, модель данных, внешние источники, дорожная карта.
- Основной сценарий — одиночные походы, локальное хранение.

### Этап 1
- React 19, TypeScript strict, Vite, React Router, русскоязычный адаптивный интерфейс.
- Создание, изменение, копирование, удаление и статусы походов; календарь дней, поиск, фильтрация.
- IndexedDB/Dexie v1, JSON-бэкап, транзакции, автоматические unit и browser-тесты.
- GitHub Pages + Actions, favicon компаса и гор.

### Этап 2
- Dexie v2: 9 новых таблиц (foods, packages, dishes, ingredients, gear, ownedGear, medical, medicalPacks, sources) без удаления старых походов, дней и настроек.
- Постоянная библиотека из пяти основных разделов с карточками, созданием, редактированием, поиском, фильтрацией и удалением.
- Питание: продукты, ккал/БЖУ, форма, отдельные фасовки с нетто, тарой, полной массой.
- Блюда с ингредиентами и связями на постоянный каталог продуктов.
- Каталожное снаряжение и собственные экземпляры с фактической массой и количеством.
- Лекарства и медизделия, конкретные имеющиеся упаковки со сроками годности.
- Источники: URL, организация, лицензия, дата получения, дата/статус ручной проверки.
- Значение null (неизвестно) принципиально отличается от подтверждённого нуля.
- Проверка внешних ключей и запрет удаления использующихся справочных записей.
- Импорт/экспорт JSON всей библиотеки с предпросмотром и подтверждением замены, экспорт CSV текущего раздела с защитой от формул.
- Полные резервные копии v2 (походы, дни, настройки и библиотека), совместимость импорта старых v1, атомарное восстановление.
- Unit-тесты миграции и целостности, browser-тесты для продуктов/фасовок и медицинских упаковок (desktop/mobile).

## Известные ограничения

- Постоянная библиотека ещё не формирует меню походов, походные комплекты вещей или аптечку. Это последующие этапы.
- Карта, GPX, реальные прогнозы, поиск официальных инструкций и другие интернет-модули пока не реализованы.
- JSON можно импортировать после проверки; CSV пока только экспортируется. Импорт произвольного XLSX потребует оригинальную книгу для точного маппинга.
- Архив библиотеки заменяет библиотеку целиком, не изменяя походы. Полный бэкап v2 заменяет все данные; старый v1 сохраняет библиотеку.
- Данные локальны в текущем профиле браузера. Нет автоматической синхронизации и полноценной PWA для открытия без сети после закрытия вкладки.
- Информация о лекарствах не заменяет официальные инструкции и назначения.

## Этап 3 — далее

- Дневное меню для каждого похода, произвольные приёмы пищи.
- Продукты/блюда из библиотеки с параметрами конкретного похода, без изменения оригиналов.
