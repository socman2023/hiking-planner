# Hiking Planner — проверка качества справочников и фотографий

Дата: 18 ноября 2026. Отчёт фиксирует **подтверждённые исправления и незавершённые проверки**, не объявляя каталог полностью выверенным.

## Исходные данные
- Excel: «Архыз_4 дня.xlsx», «Крым_4_дня_оптимизирован_все_листы.xlsx».
- Четыре списка LighterPack: a9cua5 (309), 4pg9c9 (99), gdl4a (159), 0lr1s5 (81) — всего **648 исходных строк**, не 648 подтверждённых уникальных моделей.
- Google Drive, папка «Lighterpack»: 782 файла изображений, всего около 71,7 МБ. Папка находится в подключённом пользовательском Drive, не является публичной.
- В исходном JSON LighterPack присутствует 633 URL фотографий Imgur; большинство из них имеют суффикс **s**, означающий квадратную миниатюру 90×90 пикселей.

## Найденные и исправленные проблемы
1. Ранее видимый URL фотографии не имел смысла в карточке. Он скрыт как внутренний технический источник; само фото и кнопка увеличения остаются.
2. Вместо исходной полноразмерной фотографии Imgur использовалась обрезанная квадратная миниатюра. Приложение теперь удаляет суффикс миниатюры для Imgur URL заданного формата, а CSS не обрезает фотографии и не должен растягивать маленький исходник. Полноэкранный просмотр добавлен.
3. Бренды раньше не выделялись из описания модели, иногда ошибочно бралась первая часть полного наименования. Добавлено консервативное распознавание известных брендов; неизвестные бренды оставляются пустыми, а не придумываются. **Это не равно независимой проверке каждой позиции на сайте производителя.**
4. В карточке снаряжения теперь отображается один вес «Масса, г». Исторический вес, взятый из Excel, переводится из поля «Масса производителя» в данные походного списка. Проверенной массой производителя он не считается; фактический вес собственного экземпляра остаётся отдельным.
5. Личный инвентарь из старых Excel-походов не объявляется подтверждённым наличием у пользователя. Исторические экземпляры помечаются как неподтверждённые; данные не удаляются.
6. Колонка «Вес/уп» в Excel не обязательно означает вес заводской фасовки. Автоматически импортированные строки переназначаются как «Единица N г». Пример из «Архыз — 4 дня», строка 34: Sula, 3 г на леденец, 5 шт. в день, 20 шт. за четыре дня, 60 г суммарно. Карточка меняется на «1 леденец (3 г)».
7. Из старых импортных заметок убираются автоматические комментарии о хранении, ссылках и происхождении. Место размещения относится к списку снаряжения **конкретного похода**.

## Изображения: текущий реальный охват
- В публичном репозитории **125 локальных JPEG**: 110 из первоначального импорта Excel и 15 добавленных из папки Lighterpack.
- По точной строке модели и имени изображения однозначно сопоставлено **250 позиций LighterPack** с папкой Drive.
- Файл `public/seed/drive-image-manifest.json` содержит **62 связи** между позициями LighterPack и опубликованными локальными фото: часть повторно использует уже сохранённые JPEG.
- Для оставшихся **188 из 250** точно сопоставленных позиций исходные изображения ещё не скопированы в публичный репозиторий. Для других позиций нужна отдельная верификация модели/варианта, чтобы не назначать похожую вещь вместо той же самой.
- Остальные карточки могут использовать исходные фото Imgur при доступности интернета. Наличие URL не гарантирует, что оригинал будет доступен в браузере.
- Несколько исходных снимков из Drive имеют малое физическое разрешение (например, RedFox Lhotse 100 — 242×482 пикселя). Нельзя обещать высокую детализацию, если исходный файл маленький.

## Проверки, которые ещё необходимы
- Независимая сверка производителя, конкретной версии модели, массы и характеристик со страницами производителей/документацией. Все 648 строк пока **не** прошли такую ручную проверку.
- Полная сверка остальных фотографий по моделям, включая разные размеры, поколения, цвета и аксессуары.
- Семантическая проверка оставшихся продуктов Excel: масса учётной единицы, масса реальной заводской упаковки, количество на поход. Не делать предположений по одному числу.
- Исключить дубли по моделям между четырьмя источниками, не удаляя пользовательские данные.
- Проверить права использования фотографий перед коммерческим распространением.

Принцип: отсутствие подтверждённого значения означает «неизвестно», а не ноль или догадку.
