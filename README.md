# Hiking Planner

Персональный планировщик **одиночных туристических походов** — адаптивное веб-приложение с локальным хранением данных. Основной язык интерфейса: русский. Рабочее название: **Hiking Planner**.

> **Статус: этап 2 завершён и проверен.** Уже работают походы и личная библиотека: продукты, блюда, снаряжение, медицинские карточки, собственные упаковки и источники. Походные меню, раскладки, комплекты снаряжения, реальная аптечка, GPX, карта и интернет-интеграции — отдельные следующие этапы. Заглушки не являются рабочими функциями.

## Что работает сейчас

- Несколько независимых походов; создание, поиск, фильтрация, редактирование, копирование и удаление.
- Походы на 1–365 календарных дней, даты, регион, тип активности, заметки и статус.
- Календарь: ходовой день, дорога, днёвка, другое; название, описание и заметки для каждого дня.
- Изменение даты начала со сдвигом всех дней и сохранением их содержимого.
- Увеличение длительности и сокращение **только после подтверждения удаления** последних дней.
- IndexedDB (Dexie) v2: добавлена независимая библиотека без удаления походов и дней из v1.
- Продукты и разные фасовки с массами нетто/тары; сохранение БЖУ и ккал на 100 г (пустое значение не равно нулю).
- Рецепты с отдельными ингредиентами и связями с постоянным каталогом продуктов.
- Каталожное снаряжение и собственные экземпляры с фактически измеренной массой и количеством.
- Лекарства и изделия; конкретные упаковки со сроками годности, количеством и фактической массой.
- Источники с URL, датой получения, лицензией, отметкой о ручной проверке; без автоматического доверия внешним данным.
- Поиск и фильтрация по категориям, создание/редактирование/удаление с проверкой зависимых записей.
- Экспорт библиотеки целиком в JSON и текущего раздела в CSV. Импорт JSON с проверкой данных и предпросмотром состава, затем **подтверждаемой полной заменой только библиотеки**.
- Полный резервный JSON v2 содержит походы, дни, настройки и библиотеку; поддерживается импорт старого v1 без удаления имеющейся библиотеки.
- Адаптация под компьютер и смартфон; ясные заглушки ещё не реализованных разделов.

**Не работает пока:** походные меню и раскладки, списки вещей для конкретного похода, комплектование походной аптечки, OSM-карта, GPX, прогнозы, интернет-поиск продуктов и официальных медицинских инструкций, импорт старых XLSX без подлинника, CSV-импорт, PWA и синхронизация.

## Каталоги из Excel и фотографии

При первом открытии раздела [«Библиотека»](https://socman2023.github.io/hiking-planner/library)
приложение загружает встроенный каталог из двух предоставленных Excel-книг
«Крым — 4 дня» и «Архыз — 4 дня». Происходит **сопоставление и добавление** в личную
IndexedDB, без удаления существующих карточек или походов. Повторный запуск не создаёт дублей.
Кнопка «Сверить и добавить недостающее» позволяет повторить сопоставление.

В исходных Excel: 43 продукта, 43 фасовки, 111 различных карточек снаряжения; четыре списка LighterPack добавляют до 648 исходных позиций с учётом совпадений.
(113 строк исходных таблиц, 2 повтора объединены), 27 медицинских карточек,
54 **исторические**, а не подтверждённые текущие упаковки аптечки, 9 источников.
Веса из походных таблиц выводятся отдельно от веса изготовителя;
неизвестные данные не превращаются в нули. **Фотографии из ссылок не импортированы**:
указанная папка Google Drive недоступна обоим подключённым аккаунтам, а чтение
четырёх страниц LighterPack не удалось. URL сохранены в источниках.

В карточке товара, снаряжения или медицинского изделия можно нажать
**«Добавить фото»**, выбрать 1–4 файла JPG/PNG/WebP, удалить или заменить изображения.
Фото автоматически уменьшаются до 640 пикселей и хранятся **только в локальной IndexedDB**,
а не загружаются в GitHub. Экспорт библиотеки в JSON и полный JSON-бэкап включают фото;
CSV изображений не содержит. Данные и фото видны только в том же профиле браузера,
а на другое устройство передаются резервной копией.

**Важно:** встроенные справочные записи каталога находятся в публичном репозитории,
поскольку был выбран GitHub Pages для публичного репозитория. Личные новые записи,
прикреплённые фотографии и история походов остаются локальными. Не добавляйте
частные сведения в общедоступные исходные файлы.

## Веб-версия — открыть в браузере

**Рабочая ссылка:** https://socman2023.github.io/hiking-planner/

GitHub Pages включён. После коммитов в `main` обновление собирает и публикует [автоматический workflow](https://github.com/socman2023/hiking-planner/actions/workflows/pages.yml). Установка Node.js для посещения сайта не требуется.

## Локальный запуск (только для разработчиков)

Нужны **Node.js 22** (или совместимый актуальный LTS) и **Git**. Для обычного использования приложения Node.js не нужен.

```bash
git clone https://github.com/socman2023/hiking-planner.git
cd hiking-planner
npm ci
npm run dev
```

Откройте адрес, показанный Vite, обычно **http://127.0.0.1:5173/**. Сервер нужен только для локальной выдачи файлов приложения во время разработки; отдельный облачный сервер или аккаунт для работы не требуются.

### Проверки

```bash
npm run check    # строгая проверка TypeScript

npx playwright install chromium
npm run test:e2e # браузерные тесты, включая мобильный размер
```

## Важное о данных

- Данные хранятся **в том браузере и профиле**, в котором открыто приложение. Очистка данных сайта может удалить походы.
- После существенных изменений откройте «Данные и настройки» и скачайте резервную копию v2 **походов и библиотеки**. Полный бэкап v2 заменяет все эти данные; старый бэкап v1 заменяет только походы/дни/настройки и **не удаляет библиотеку**.
- В «Библиотеке» JSON-импорт заменяет только записи библиотек и не изменяет походы. Перед заменой скачайте копию.
- На разных устройствах нет автоматической синхронизации; перенос возможен через JSON-копию.
- **Offline-first хранение не означает готовую PWA**: после закрытия вкладки запуск интерфейса без сервера/сети ещё не гарантирован. PWA будет на последнем этапе.
- Никакие персональные маршруты, бронирования, медданные или секретные ключи не должны попадать в GitHub.

## Техническая основа

React + TypeScript + Vite; React Router; IndexedDB + Dexie; Lucide; Vitest + fake-indexeddb + Playwright. Для первой версии **не нужны** Cloudflare, Supabase, платные API, авторизация или отдельный бэкенд.

Визуальное направление вдохновлено демонстрационным HTML-прототипом, но архитектура и вычисления создаются заново. Название прототипа не используется.

### Марка, модель и собственные экземпляры

Бренд и модель отображаются отдельно: например, **Therm-A-Rest** / **NeoAir Uberlite**, а размеры 183 × 51 × 6,4 см, R-Value 2,0 и температурный ориентир «до 0» записываются в самостоятельные поля по исходному LighterPack. Это сведения из списка, не замена официальной заводской спецификации. **Все предметы предоставленных пользователем списков считаются личным снаряжением пользователя**. Учитывается количество из списка, при повторном упоминании в разных поездках количество не суммируется. Место размещения относится только к конкретному походу. Сохраняется оригинальное описание источника для сверки.
