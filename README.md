# Hiking Planner

Персональный планировщик **одиночных туристических походов** — адаптивное веб-приложение с локальным хранением данных. Основной язык интерфейса: русский. Рабочее название: **Hiking Planner**.

> **Статус: этап 1 реализован и проверен.** Уже работают создание и ведение походов, календарь, резервное копирование. Маршруты, карты, питание, снаряжение, аптечка и интернет-каталоги разрабатываются на следующих этапах. Не путать заглушки этих разделов с готовым функционалом.

## Что работает сейчас

- Несколько независимых походов; создание, поиск, фильтрация, редактирование, копирование и удаление.
- Походы на 1–365 календарных дней, даты, регион, тип активности, заметки и статус.
- Календарь: ходовой день, дорога, днёвка, другое; название, описание и заметки для каждого дня.
- Изменение даты начала со сдвигом всех дней и сохранением их содержимого.
- Увеличение длительности и сокращение **только после подтверждения удаления** последних дней.
- Локальная IndexedDB (Dexie) со схемой v1 и транзакционными операциями.
- Экспорт полного текущего набора (походы, дни и настройки) в JSON.
- Проверка JSON-копии перед импортом; восстановление только с подтверждением полной замены.
- Адаптация под компьютер и смартфон; ясные заглушки ещё не реализованных разделов.

**Не работает пока:** OSM-карта, GPX, меню, раскладка, личная библиотека товаров и медикаментов, прогнозы, интернет-поиск, полноценная PWA-установка, синхронизация между устройствами.

## Веб-версия — открыть в браузере

**Адрес после первой успешной публикации:** https://socman2023.github.io/hiking-planner/

Для первой публикации владелец репозитория один раз выбирает **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем необходимо повторно запустить [Publish Hiking Planner (GitHub Pages)](https://github.com/socman2023/hiking-planner/actions/workflows/pages.yml) (кнопка «Run workflow» или «Re-run failed jobs» в последней попытке). В дальнейшем публикация запускается автоматически после обновления `main`.

**Статус на 18 ноября 2026:** автоматическая сборка веб-версии прошла успешно, но первое развёртывание остановилось на шаге Configure Pages, поскольку GitHub Pages ещё не был включён в настройках репозитория. Не считайте ссылку рабочей до успешного зелёного запуска workflow.

## Локальный запуск (только для разработчиков)

Нужны **Node.js 22** (или совместимый актуальный LTS) и **Git**. Для обычного использования приложения Node.js не нужен.

```bash
git clone https://github.com/socman2023/hiking-planner.git
cd hiking-planner
npm ci
npm run dev
```

Откройте адрес, показанный Vite, обычно **http://127.0.0.1:5173/**. Сервер нужен только для локальной выдачи файлов приложения во время разработки; отдельный облачный сервер или аккаунт для работы не требуются.

Если `package-lock.json` ещё не создан в GitHub, один раз выполните `npm install` вместо `npm ci`. После формирования lockfile пользуйтесь `npm ci`.

### Проверки

```bash
npm run check    # строгая проверка TypeScript
npm test         # модульные тесты
npm run build    # production-сборка
npx playwright install chromium
npm run test:e2e # браузерные тесты, включая мобильный размер
```

CI: [GitHub Actions](https://github.com/socman2023/hiking-planner/actions). Проверочный PR этапа 1 прошёл TypeScript, 11 unit-тестов, сборку и 4 E2E-теста на Chromium (desktop/mobile).

## Важное о данных

- Данные хранятся **в том браузере и профиле**, в котором открыто приложение. Очистка данных сайта может удалить походы.
- После существенных изменений откройте «Данные и настройки» и скачайте резервную копию. Восстановление **заменяет**, а не объединяет локальные записи.
- На разных устройствах нет автоматической синхронизации; перенос возможен через JSON-копию.
- **Offline-first хранение не означает готовую PWA**: после закрытия вкладки запуск интерфейса без сервера/сети ещё не гарантирован. PWA будет на последнем этапе.
- Никакие персональные маршруты, бронирования, медданные или секретные ключи не должны попадать в GitHub.

## Техническая основа

React + TypeScript + Vite; React Router; IndexedDB + Dexie; Lucide; Vitest + fake-indexeddb + Playwright. Для первой версии **не нужны** Cloudflare, Supabase, платные API, авторизация или отдельный бэкенд.

Визуальное направление вдохновлено демонстрационным HTML-прототипом, но архитектура и вычисления создаются заново. Название прототипа не используется.
