# Hiking Planner

Персональное веб-приложение (в перспективе PWA) для подготовки **одиночных туристических походов**. Рабочее название: **Hiking Planner**. Язык основного интерфейса: русский.

> **Статус:** этап 0 — проектирование. Работающего приложения в репозитории пока нет. Запускать `npm install` / `npm run dev` на этой стадии бессмысленно.

## Цель

Создавать и хранить несколько походов произвольной длительности; планировать маршрут и треки, питание и продуктовую раскладку, личное снаряжение, аптечку, транспорт, расходы и контрольные списки. Локальная база данных работает без обязательной регистрации и без собственного сервера. Интернет используется для поиска сведений и обновления прогнозов; сохранённые данные доступны офлайн.

Основной сценарий — **один турист**. Совместная работа, разделение группового веса и коллективные взаиморасчёты **не входят в первую версию**.

## Принятые решения

1. React + TypeScript + Vite; адаптивный интерфейс, дизайн референсного HTML используется как визуальное направление, **не как исходная архитектура**.
2. IndexedDB через Dexie; миграции схемы, экспорт/импорт полного JSON-бэкапа, затем PWA.
3. OpenStreetMap как источник картографических данных; карта с Leaflet в первом картографическом релизе. Провайдер тайлов выбирается отдельно в соответствии с правилами использования.
4. Источники сведений подключаются через независимые адаптеры. Нет обязательных платных API, собственного сервера или облачной авторизации.
5. Данные, полученные из интернета, имеют происхождение и дату проверки; локальные подтверждённые значения нельзя тихо перезаписывать.
6. Медицинские сведения — справочная информация, а не назначения или автоматическая оценка безопасности лекарств.
